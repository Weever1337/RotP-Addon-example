# Non Powers Tutorial

A guide how to do your own Non Power like Hamon, Vampirism or Pillarman! 

In this tutorial we have Tutorial Non Power with 3 abilities and a small lesson how to work with Sync-Packet and with Non Power's data. 

## [New/changed files](https://github.com/StandoByte/RotP-Addon-example/compare/master...non-powers):
- `build.gradle` and `gradle.properties` - we use a newer version of the RotP mod, which includes a better way to set a color for Non Powers<br>
- `assets/<mod_id>/geo/<model_id>.geo.json` - removed stand example one<br>
- `client/...` - removed stand example one<br>
- `assets/<mod_id>/entity/stand/<stand_name>.png` - removed stand example one<br>
- `assets/<mod_id>/power/<stand_name>.png` - replaced stand example one with non-power example one<br>
- `assets/<mod_id>/textures/action` - replaced the textures from the stand example with the ones from Tutorial Non Power<br>
- `init/InitSounds.java` - commented (//) sounds because we do not use them in example one.<br>
